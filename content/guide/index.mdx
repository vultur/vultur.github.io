# 排版规范

## 标题

```markdown
## 二级标题

### 三级标题

#### 四级标题
```

### 三级标题示例

段落跟随标题，形成清晰的阅读层级。

## 摘录与正文

普通段落为摘录，`article` 为正文。

```mdx
<article>这是正文、评论或札记。</article>

<article className="initial">这是带首字强调的正文。</article>

<span className="nextra-initial">首词</span> 可以手动强调。
```

## 文本样式

**加粗**、_斜体_、~~删除线~~ 可以表达不同层级的强调。

补充样式：<ins>下划线</ins>、上标<sup>1</sup>、下标<sub>2</sub>、<mark>标记</mark>、<wavy>波浪线</wavy>。

<small>小字适合用于版本说明、译者注、校订说明或不宜进入正文节奏的补充信息。</small>

```markdown
**加粗**
_斜体_
~~删除线~~
<ins>下划线</ins>
上标<sup>1</sup>
下标<sub>2</sub>
<mark>标记</mark>
<wavy>波浪线</wavy>
<small>小字说明</small>
```

这些格式也可以单独作为段落使用，单独成段时会保持首行缩进：

```mdx
<mark>这是一段标记段落。</mark>

<wavy>这是一段波浪线段落。</wavy>
```

## 引用

> 所谓格式，不只是视觉装饰，也是阅读秩序。它让读者知道哪些内容是正文，哪些内容是旁注、例证或保留意见。
>
> <cite>排版规范</cite>

```markdown
> 这是一段引用。
>
> <cite>出处</cite>
```

## 表格

| 类型   | 语法                     | 用途           |
| ------ | ------------------------ | -------------- |
| 正文   | `<article>...</article>` | 书写评论或札记 |
| 标记   | `<mark>文本</mark>`      | 标记重点       |
| 波浪线 | `<wavy>文本</wavy>`      | 标记疑问或保留 |
| 引用   | `> 文本`                 | 呈现引文       |
| 代码   | `` `code` ``             | 标记命令或字段 |
| 链接   | `[文本](url)`            | 指向外部资料   |
| 脚注   | `[^1]`                   | 补充来源说明   |

```markdown
| 类型 | 用途 |
| ---- | ---- |
| 正文 | 评论 |
| 引用 | 引文 |
```

## 脚注

脚注用于补充来源、版本或译注信息，不打断主要阅读节奏。[^1]

同一段也可以使用多个脚注。[^2][^3]

```markdown
正文内容。[^1]

同一段也可以使用多个脚注。[^2][^3]

[^1]: 这里是脚注内容。

[^2]: 这里是第二条脚注。

[^3]: 这里是第三条脚注。
```

[^1]: 脚注适合放置出处、异文、译名说明、版本说明，正文中不宜过多使用。

[^2]: 多个脚注按定义顺序集中显示。

[^3]: 脚注文字宜短，不应喧宾夺主。
