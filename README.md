## 文件目录

- 作者：`content/authors/[作者].mdx`
- 作品：`content/books/[作品].mdx`

- 肖像：`public/images/authors/[作者].jpg`
- 封面：`public/images/books/[作品].svg`

## 作者字段

```mdx
---
title: "路易丝·格丽克"
description: "美国诗人"
---
```

## 作品字段

```mdx
---
title: "阿弗尔诺"
authors:
    - name: "路易丝·格丽克"
      country: "美国"
published: 2006
description: "借珀耳塞福涅神话书写母女、衰老与失落"
---
```
